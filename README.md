# Accounting Portfolio

Personal portfolio website for Sterling Napurano, a senior Accounting student at Rutgers Business School interested in audit and public accounting.

## Website sections
- Personal statement
- Skills and strengths
- Two accounting practice projects with downloadable Excel workbooks

## Projects
- **Budget vs. Actual Analysis** — simulated expense variance analysis.
- **Audit Transaction Review** — simulated accounts payable exception testing.

Both workbooks use fictional data and were prepared with AI assistance for learning and portfolio demonstration.

# Accounting Portfolio

Personal portfolio website for Sterling Napurano, a senior Accounting student at Rutgers Business School interested in audit and public accounting.

## Website sections
- Personal statement
- Skills and strengths
- Two accounting practice projects with downloadable Excel workbooks

## Projects
- **Budget vs. Actual Analysis** — simulated expense variance analysis.
- **Audit Transaction Review** — simulated accounts payable exception testing.

Both workbooks use fictional data and were prepared with AI assistance for learning and portfolio demonstration. They should be reviewed and understood before being presented as personal work.

## GitHub Pages deployment
1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `README.md`, and the entire `projects` folder to the **repository root**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish and open the displayed website URL.

If your repository is named `accounting-portfolio`, the URL is normally `https://YOUR-USERNAME.github.io/accounting-portfolio/`.
